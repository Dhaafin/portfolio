# DESIGN GUIDELINES: LUXURY NONCHALANCE

## 1. VISION
The brand identity is "Cool but indifferent." It is a state-of-the-art digital experience that doesn't beg for attention. It feels like an expensive watch or a minimalist architectural project: premium materials, perfect execution, but zero "salesy" energy.

## 2. COLOR SYSTEM (DEEP BLUE)
We use a spectrum of sophisticated blues to create depth without using pure black.

- **Background**: `hsl(222 47% 4%)` — The primary canvas. A deep, midnight blue.
- **Surface**: `hsl(222 47% 7%)` — For cards and elevated elements (Glassmorphic).
- **Accent**: `hsl(217 91% 60%)` — Electric blue for critical interactions only.
- **Muted**: `hsl(215 20% 65%)` — For secondary text and "damp" details.

## 3. TYPOGRAPHY (JOST)
- **Heading 1**: 900 weight, tight tracking (-0.05em), lowercase preferred for the "cool" factor.
- **Body**: 400 weight, generous line height (1.6) for readability.
- **Copywriting Style**: "Damp." Minimalist. Cynically brief. No marketing fluff.

## 4. INTERACTION & MOTION
- **Easing**: Custom cubic-bezier `(0.23, 1, 0.32, 1)` for that "expensive" feel.
- **Hover States**: Subtle opacity shifts or scale changes (1.02x). Nothing bouncy.
- **Transitions**: 800ms+ durations. We are in no rush.

## 5. UI PATTERNS
- **Whitespace**: Overuse it. If you think there's enough space, add 20% more.
- **Glassmorphism**: Border-only highlights. Background blurs should be heavy (12px-20px).
- **Borders**: `hsla(217, 91%, 60%, 0.1)` — Extremely subtle sapphire strokes.
